Esta página já traz o projeto inteiro guardado dentro dela (684 KB). Não precisa de internet para salvar.

Manual de instrução
  1. Toque no botão verde acima para salvar o Assistente-Juridico-modular-17-10-a.zip.
  2. Para usar no celular/site: entre no seu site do jurídico (Netlify → aba Deploys → arraste o zip) ou, no Mini SK, abra o zip como projeto e publique.
  3. Para o programa do computador (.exe): no Mini SK, 🗂 Projetos → Abrir .zip como projeto → este zip → confira que a prévia mostra o Assistente Jurídico (e não uma lista de peças) → 📦 APK → 🖥️ Enviar e gerar .exe (repositório: juridico-pc).
  4. Depois de abrir: aba 🧪 Códigos para guardar os seus códigos; ⚙️ Config → Qual IA usar para escolher OpenRouter, Claude etc.; ⚙️ Config → ☁️ Google Drive para ligar o Drive direto (passo a passo lá dentro).
  5. Seus documentos, modelos e conversas continuam: nada é apagado ao atualizar.
Se o botão não salvar
  • Abra esta página no computador, com dois cliques (abre no Chrome ou Edge), e toque no botão de novo.
  • Se o Chrome perguntar, escolha Manter.
  • Guarde também ESTA página num pen drive: enquanto você tiver ela, tem o projeto.
